# 商城登记材料

圆屏的应用环从 Yaykit 商城的应用目录取名字和图标（`yk_catalog.h`：Yay 联网时写，应用固件只读）。
USB 装进去、还没登记的应用，应用环里显示 slug 和它的第一个字母。名字和图标在立项、上架时交给 Yaykit 登记。

| 文件 | 是什么 |
|---|---|
| `icon.svg` | 图标源文件：一台小收音机，圆屏主题色（`yk_round.h`） |
| `icon-64.png` | 64 × 64，应用目录里图标的尺寸 |
| `icon-512.png` | 512 × 512，商城页面和预览用 |

名字：中文「收音台」，英文「Radio」（`app.json` 的 `name`）。
