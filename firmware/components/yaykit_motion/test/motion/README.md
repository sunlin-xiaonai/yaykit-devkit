# 姿态录音（主机测试回放）

真机用 `motion log <秒>` 录下的六轴原始数据（传感器坐标，g 和 dps），`yaykit/firmware/tools/yay_dev.py motion-log` 存成 CSV。`test/run.sh` 回放这里所有的 `.csv`，按文件名前缀检查（`test_motion.c` 的 `test_recordings`）：

| 前缀 | 动作 | 必须 | 不能 |
|---|---|---|---|
| `flat-` | 平放不动 | — | 摇、拿起 |
| `look-` | 拿起来看 | 拿起 | 摇 |
| `shake-light-` | 轻摇 5 秒 | 摇 | — |
| `shake-hard-` | 狠摇 5 秒 | 摇 | — |
| `shake-walking-` | 摇着走 | 摇 | — |
| `put-down-` | 放下 | — | 摇 |
| `handoff-` | 递给别人 | 拿起 | 摇 |
| `pass-around-` | 一圈人传 30 秒 | 「在动」中断不超过 1 秒（`still` 最多一次，在最后） | — |
| `face-down-` | 扣下 | 扣下 | — |
| `upright-` | 竖放 | 竖放 | — |
| `turn-in-hand-` | 在手里转 | — | — |
| `knock-` | 碰一下桌子 | 1.5 秒内判成静止、之后一直静止、学到静止读数 | 摇、拿起 |
| `held-` | 拿在手里（最后可以放回桌上） | 拿着时每段「静止」都短于 3 秒；静止读数只在最后放下以后才学（或者没学） | — |
| `rest-` | 放着不动（平放或立着），按旧规则（跟 1 g 比、陀螺不减零偏）会判成拿着 | 1.5 秒内判成静止、之后一直静止、学到静止读数；旧规则至少断一次或从没静止 | 拿起、摇 |
| `boot-` | 刚启动就开始录、放着不动 | 1.5 秒内判成静止、之后一直静止 | 拿起、摇 |

聚会玩设计文档「姿态检测」要的 12 段。录的时候不含任何个人信息（只有时间和六轴读数）。前 12 种还没录：需要有人拿着设备做动作。

已录（2026-10-23，`yay_dev.py motion-log`，聚会玩开发版里录，224 Hz）：

| 文件 | 设备 | 情形 |
|---|---|---|
| `rest-flat-0963g-1.csv` | 测试机 A | 平放（实际斜约 10°）20 秒，‖a‖ = 0.963 g、陀螺零偏 2.6 dps；旧规则 20 秒里断 2 次 |
| `rest-upright-gyro-bias-1.csv` | 测试机 B | 立着放 20 秒，‖a‖ = 1.023 g、陀螺零偏 9.5 dps；旧规则从没判成静止 |
| `boot-flat-1.csv` | 测试机 A | 从 Yay 冷启动聚会玩，开机 2.9 秒（姿态任务刚起来）开始录，平放 10 秒 |
| `boot-upright-gyro-bias-1.csv` | 测试机 B | RTS 复位后开机 2.0 秒开始录，立着放 10 秒：零偏 9.5 dps 还没学到的时候；旧规则从没判成静止 |
| `held-then-put-down-1.csv` | 测试机 A | 用户拿在手里看屏幕约 31 秒、再放回桌上，共 45 秒；拿着时陀螺最稳的一秒每轴波动 0.72 dps |
| `held-steady-1.csv` | 测试机 A | 用户手肘撑在桌上、尽量不动地拿着 25 秒；最稳的一秒 0.55 dps |
| `knock-table-1.csv` | 测试机 A | 放在桌上，用户在旁边敲了几下桌面，35 秒；敲的那几秒 ‖a‖ 跳 0.02–0.045 g，陀螺不到 1 dps；旧规则断 24 次 |
| `rest-desk-nudged-1.csv` | 测试机 A | 放在桌上，旁边有人碰到（陀螺偶尔到 3.8 dps），20 秒，0.960 g |

「拿在手里」「碰桌子」10-23 用户在测试机 A上录了（上面 `held-`、`knock-` 四段），换掉了之前在静止录音上叠加模拟手抖和敲击的测试。
