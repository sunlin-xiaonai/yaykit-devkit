# yaykit_motion

设备的姿态和动作（公共层计划 P12）。QMI8658（I2C `0x6B`，和触摸、编解码器共用总线），加速度计 ±8 g、陀螺仪 ±1024 dps、约 224 Hz，一个任务每 4 ms 读一次（采样计数没变就跳过），每个采样读一次。

从呼吸之间的 `breathe/main/motion.c`（10 Hz、只开加速度、只有扣下和拿起）长出来；呼吸里那份不删，呼吸会话以后自己切过来（呼吸开发文档第九节 P4）。

| 文件 | 内容 |
|---|---|
| `include/yaykit_motion.h` | 接口：事件、状态、数据流、拿的人方向、阈值、标定 |
| `yk_motion_core.c`、`yk_motion_core.h` | 纯 C：互补滤波估重力、线加速度、静止和在动、各事件、拿的人方向、CSV；`test/run.sh` 在电脑上测 |
| `yaykit_motion.c` | 设备侧：传感器任务（每 4 ms 读一次状态、采样计数和六轴，新采样才算）、NVS 标定、控制台 |
| `test/motion/` | 真机录的姿态 CSV，主机测试按文件名回放（见那里的 README） |

## 坐标

- 屏幕坐标：x 向右、y 向下（和像素一样）、z 从玻璃朝外。
- 重力向下：玻璃朝上平放时是 (0, 0, −1) g。线加速度 = 加速度 − 重力的反作用。
- 陀螺：屏幕坐标下的度每秒，`gyro[2] > 0` 是看着屏幕顺时针转。
- 屏幕上的角度：从正上方（12 点）顺时针，0–360。「拿的人方向」= 屏幕斜向他时重力在屏幕平面上的分量的方向。
- 内部在右手系「设备坐标」（x 右、y 上、z 朝外）里算，标定把传感器轴映射到设备坐标。测试设备上传感器 z 朝背面（呼吸实测：玻璃朝上 z = −1 g），默认映射 `{1, -2, -3}`；x、y 的方向要真机确认（`motion cal`）。

## 事件和阈值

照聚会玩设计文档「姿态检测」和呼吸开发文档第六节；`yk_motion_thresholds_t` 每项都能改。

| 事件 | 判定（默认） |
|---|---|
| 平放 | 玻璃法线和竖直夹角 < 25°，持续 500 ms |
| 竖放 | 夹角 > 60°（且 < 120°），持续 500 ms；`angle` = 哪边朝上，变了（按 90° 取整）再报一次 |
| 拿起 | 从静止开始：线加速度 > 0.15 g 或转速 > 25 dps 持续 80 ms，或倾角比静止时变了 > 20°；两次之间 ≥ 2 秒；玻璃已经朝下（向上分量 < −0.5 g）时不算 |
| 放下 | 拿起或摇过之后，静止满 300 ms（见下面「静止」）；带开始静止前 0.5 秒的拿的人方向和可信度 |
| 摇开始 / 摇结束 | 1 秒内至少 3 个 > 0.8 g 的线加速度峰，相邻两个方向相反；60 ms 内的峰算同一个（碰桌子的振铃）；400 ms 没有峰就结束。力度 = 最近 250 ms 线加速度的均方根，0.5–3 g 映射到 0–1 |
| 扣下·试探 / 扣下 / 翻回 | 向上分量 < −0.75 g 持续 250 ms / 600 ms；> −0.30 g 持续 400 ms 翻回。有陀螺时看重力估计（转得再快也跟得上）；只有加速度时（陀螺读数全是 0，呼吸可能这样喂）看加速度自己的向上分量（低通约 50 ms），转完约 600 ms 判出 |
| 在动 / 静止 | 最近 1 秒内有 > 15 dps 或 > 0.08 g |

**静止**（`state.still`，聚会玩用它判「拿着」，也决定放下、拿起）：‖a‖ 和这台设备自己静止时的读数差 < 0.04 g，减掉零偏的转速 < 4 dps，满 300 ms。

- 「自己静止时的读数」和陀螺零偏，在「很稳的一秒」里学：这一秒里 ‖a‖ 的标准差 < 0.003 g、陀螺每个轴 < 0.4 dps（测试机静止时分别约 0.001 g、0.2 dps），就把这一秒的平均 ‖a‖ 当作静止读数（只认 0.85–1.15 g），平均转速当作零偏。
- 为什么：测试机平放时 ‖a‖ 只有 0.963 g，噪声一冒就出了 1 g ± 0.04 的门，聚会玩一直当作「拿着」、不熄屏；另一台的陀螺零偏有 9.5 dps，超过 4 dps，而以前零偏只在判成静止以后才学，于是从来判不成静止。
- 手拿着时转速的波动大于 0.4 dps，学不到：用户实拿（10-23 真录）最稳的一秒每轴 0.55 dps（手肘撑着桌子）、平时拿着 0.72 dps 以上；放着时约 0.13 dps，旁边敲桌子也不到 0.15 dps。就算学了，学到的东西（重力的长度、零偏）跟怎么拿着几乎无关。‖a‖ 的波动分不开这两种（拿得稳时也只有 0.002–0.003 g），靠的是陀螺。以前「静止时每个样本都往读数上拉零偏」的做法去掉了：手稳到 4 dps 以内时零偏会被手拖着走。
- 刚开机、还没有很稳的一秒时：‖a‖ 跟 1 g 比，门放宽到 0.08 g。
- 不存进 NVS：每次启动放稳 1 秒就学到；存下来的话，学错的值会一直带着，零偏也会随温度变。`imu_cal` 里标定时存的零偏照旧当作开头的值。

重力估计：陀螺转、加速度在接近 1 g 时慢慢拉回（0.3 秒）；两者差 60° 以上持续 250 ms（没有陀螺、或者一下翻过去），就直接从加速度重新开始，不会卡在反方向。

## 用法

```c
#include "yaykit_motion.h"

static void on_motion(const yk_motion_event_t *ev, void *ctx) {
    // 在姿态任务里调：只记下来，界面在 LVGL 任务里改
}

yk_motion_config_t cfg = {.on_event = on_motion};
if (yk_motion_start(&cfg) != ESP_OK) { /* 没有传感器：照常运行，没有姿态 */ }
yk_motion_stream(on_samples, NULL);               // 聚会玩的骰子：每 20 ms 一批样本
float angle, conf;
yk_motion_holder(500, &angle, &conf);             // 炸弹爆炸前 0.5 秒拿在谁手里
```

固件的 `EXTRA_COMPONENT_DIRS` 加 `components/yaykit_motion`，`main` 的 `REQUIRES` 加 `yaykit_motion`。在 `board_init()`（或 `board_display_start()`）之后启动。

## 标定

存在共享 NVS `yk_pref/imu_cal`，所有固件读同一份。开发版控制台：`motion cal flat`（玻璃朝上平放）、`motion cal upright`（立起来、屏幕上的字是正的）、`motion cal save`、`motion cal reset`。

## 录数据

`motion log <秒>` 打出带序号的 CSV 行（`MOTION_CSV_BEGIN`、`MC <序号> t_us,ax,ay,az,gx,gy,gz`、`MOTION_CSV_END`，传感器坐标，g 和 dps），`yaykit/firmware/tools/yay_dev.py --port <口> motion-log <秒> <文件>` 存成文件放进 `test/motion/`。`motion` 另打一行 `MOTION_REST settled=… rest_g=… gyro_bias=…`：学到的静止读数和零偏。
