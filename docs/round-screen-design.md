# 圆屏应用设计规范 v1

> 这就是 Yaykit 自己用的那份规范，导出时只加了这一句：文中指向 `docs/design/…` 的链接是我们内部的文档，开发包里没有，要看哪一条就在需求单里问。

2026-10-20 起草。适用于 tikpal-r1 圆屏上的 Yay 主固件和全部扩展应用：聚会玩、呼吸之间、口语陪练、作业伙伴、面对面翻译。各应用的界面文档引用本规范，只写自己特有的部分；和本规范冲突时，先改本规范再改应用。

公共层怎么做（会话、安装、记忆、设置）见 [扩展应用公共层开发计划](../../../docs/design/extension-platform.md)。主固件的界面细节见 [Yay 圆屏开发文档](../../../docs/design/yay-device.md) 第 3、6.5 节。

## 1. 原则

1. **一屏一个主角，把圆填满。** 中心放主角（Yay、光球、骰子、转盘、田字格、译文），边缘一圈表示状态和进度。不用方形列表和卡片墙。
2. **表情多、字少。** 一屏最多两处文字；提示一句不超过 8 个字（字幕和译文除外）。能用 Yay 的表情、边缘环、图形说清的，不写字。
3. **永远能互动。** 任何画面、任何状态，触摸和侧键都要在 100 ms 内有看得见的回应。没有"死屏"，没有只能干等的画面。
4. **不沮丧。** 没网、点数用完、出错时，Yay 不哭、不睡、不道歉连篇，只给一个小提示和下一步。闭眼休息只用在快息屏时。连接中不说"没网"，显示"正在连"。
5. **大气来自克制。** 留白、大字号、少元素、流畅的动效、好听的声音，而不是装饰多。
6. **每个应用里都有 Yay。** Yay 是主持人、陪练、陪写或传话的人，不是贴图。它看向正在说话的人，对结果有反应。
7. **声音代替震动。** 设备没有马达。每次确认、拨动、结果都有一个短而好听的声音。
8. **外圈说状态和进度，字要够大。**（2026-10-22 用户定）用户原话：「可以使用外围圆形的颜色表达状态，进度条效果表示进度，文字也要足够大」。状态用边缘环的颜色说（第 5 节），进度把边缘环画成进度条，不在屏中间另放小进度环；页面上的字用大号，一臂远能看清，宁可少几个字。
9. **二维码页只为扫码。**（2026-10-22 用户定）用户原话：「二维码放足够大，不要形象，因为主要目的是绑定，全屏二维码都行」。凡是二维码页（首次添加、设置 › Wi-Fi、换个网络），不放 Yay 形象，二维码在安全圆里尽量大，必要时铺满；只留配对码和一句最短的提示，扫码以后的进度和结果交给边缘环。这一条优先于第 6 条。

## 2. 屏幕与几何

466 × 466 圆形 AMOLED，圆心 (233, 233)。黑色不发光，画面像浮在桌面上。

| 区域 | 半径 | 放什么 |
|---|---|---|
| 边缘环带 | 214–233 | 边缘环（第 5 节）、刻度、拨盘手势区（外圈 65 px 内都算） |
| 内容区 | ≤ 200 | 所有文字。超出就会被圆切掉 |
| 核心区 | ≤ 140 | 主角 |

**一行文字能放多宽**：离圆心上下 d 像素处，可用宽度 = 2 × √(200² − d²)。

| 离圆心 d | 0 | 60 | 100 | 140 | 170 |
|---|---|---|---|---|---|
| 可用宽度 | 400 | 381 | 346 | 285 | 210 |

- **沿弧线排字**只用于 8 个字以内的短标签（逐字旋转贵），字幕一律水平排。
- **触控**：可点区域不小于 96 × 64（视觉可以更小，点击区外扩）；主按钮直径不小于 92；两个可点区域之间至少隔 12。
- **多人围看**（聚会玩、面对面翻译平放时）：以图形和数字为主；结果转向对应的那个人；需要给对面的人看字时，那一半整体旋转 180°。
- **方向**：竖放（立着或拿在手里）时只有一个正方向；平放时由应用决定朝向。姿态由共用的姿态组件给出（公共计划 P12）。

## 3. 颜色

和主固件 `yay_ui.c` 一致。底色用 paper。入睡和夜里用的画面（呼吸之间入睡场景的主页、练习、晚安）用纯黑 #000000：黑屋里 paper 会照出一整块灰色圆盘。

| 名字 | 值 | 用在 |
|---|---|---|
| paper | #171C19 | 背景 |
| ink | #FAF7EF | 主要文字、Yay 的身体 |
| ink2 | #A5AA9E | 次要文字 |
| ink3 | #737A70 | 提示、不可用、连接中的那段弧 |
| panel | #30372F | 面板、未选中 |
| coral | #DF795D | 主动作、说话按钮、倒计时、更正的词、需要注意 |
| coral-text | #EE9A80 | 深底上珊瑚色的小字 |
| sage | #9FB38C | 在听、进度、选中、成功 |
| sage-text | #B9CAA8 | 深底上鼠尾草色的小字 |
| amber | #E3A857 | 提醒、电量低、点数快用完 |
| cream | #F3E6C8 | 点缀、高光 |

- **不用蓝色**，也不用青、蓝紫这类接近蓝的颜色。
- **大面积不用 ink 和 cream 铺满**：AMOLED 上刺眼，也费电。
- **多人的颜色**（聚会玩，2–8 人，聚会玩设计会话定稿）：按座位从侧键那一侧顺时针分配：珊瑚 #DF795D、奶油 #F3E6C8、陶土 #B7654A、鼠尾草 #9FB38C、梅子 #B98AA6、琥珀 #E3A857、橄榄 #808B4F、沙 #CDB18E——单数座位暗、双数亮，相邻两人明暗交替。每人另带 1–8 个点做双重编码，色弱的人靠点数也分得清。

## 4. 字体与字号

只有共享字体包里的一种字重（简中、日文、拉丁含西语；应用不自带字体）。大数字和特大字可以预先画成图。

| 用途 | 字号 | 常量（`yaykit_ui` 的 `yk_round.h`） |
|---|---|---|
| 主角大字（田字格里的字、骰子点数、倒计时） | 96–160，按应用定 | `YK_SIZE_HERO_MIN`、`YK_SIZE_HERO_MAX` |
| 译文、字幕 | 24；放不下三行时缩到 20 | `YK_SIZE_SUBTITLE`、`YK_SIZE_SUBTITLE_SMALL` |
| 页面标题、语言名 | 24（22 也可以） | `YK_SIZE_HEADING` |
| 状态行、按钮文字、"我听到" | 18 | `YK_SIZE_STATUS` |
| 最小（额度、说明、底部提示） | 16，不再更小 | `YK_SIZE_MIN` |

- 用常量，不写数字。主固件：顶部状态 18（`YK_SIZE_STATUS`）、正文 22、边说边出的字 24、提示和说明 16（`YK_SIZE_MIN`），二维码页的配对码 32。
- 字体是运行时渲染的 TrueType（`cjk_font_get(px)`），哪个字号第一次用到才建，不用预先生成。

- 中文不加粗、不斜体；英文句首大写，不全大写。
- 数字用阿拉伯数字；时间用 `12:30`、`5 分钟`。

## 5. 边缘环

边缘环是圆屏的通用语言：半径 226、宽 6 px、从正上方顺时针。每个应用都用它，含义一致。

| 状态 | 样子 |
|---|---|
| 在听 | sage，随音量起伏 |
| 正在连（网络、云端） | ink3 一小段弧慢慢转，不显示"没网" |
| 想 / 等云端 | sage 一小段弧来回扫 |
| 倒计时、专注计时 | coral，剩余的部分 |
| 进度（下载、安装） | sage，已完成的部分 |
| 调数值（音量、时长） | 外圈刻度亮起，每走一格响一声 |
| 结果 / 完成 | sage 合成整圈后淡出 |

同一时间只显示一种。应用自己的主角也可以占用边缘（转盘、拨盘），这时不再画边缘环。

- **主角拨盘可以加宽**到 12–16 px（作业伙伴的 60 分钟计时盘，隔着桌子要看得见）。在听、在想时照样换成 sage，结束后回到自己的颜色。
- **多人分屏时只亮一半**：面对面翻译平放分成上下两半时，「在听」只亮说话人那一侧的半圈，两个人都看得出是谁在说。

## 6. 手势和侧键

所有应用一致。应用可以不用某个手势，但不能把它挪作他用。

| 操作 | 含义 |
|---|---|
| 轻触 | 主动作（开始、暂停、选择、换） |
| 按住屏幕 | 语音类应用：说话，松开发送；按住时手指移开或换手点屏幕取消 |
| 侧键按住 | 语音类应用：说话（和 Yay 一样）。练习类（呼吸）：按住约 0.9 秒结束——按下 0.3 秒后边缘画一段 coral 弧，满了就结束，夜里不看屏幕也能停。其他应用不用；应用没用掉的按住、又没有自己的对话，系统问「回到 Yay 说？」（点屏幕回去 · 短按留下，`yk_app_on_key()`） |
| 侧键短按 | 停下（播放、计时）或返回上一层；在应用主界面就息屏（和 Yay 一样）。要等 0.45 秒确定不是双击才生效（`delay_tap`） |
| 双击侧键 | 打开应用环（系统保留，应用不能占用）：中间是 Yay，点它回家；点别的扩展直接换过去；点没装的先回 Yay 再装（`YK_API_LEVEL` 3，见 `docs/design/device-controls.md` §4） |
| 左滑 | 设置（和 Yay 一样）。没有设置页的应用，左右滑换主角或模式（呼吸换场景、聚会玩换游戏）。平放多人围着用时，左右按当前朝向（姿态组件给出的「朝向坐标」）换算，不按屏幕的固定方向 |
| 右滑 | 应用的第二个页面（如果有，例如记录）；没有设置页的应用见上一行 |
| 下滑 | 状态：网络、电量、今天的点数 |
| 沿边缘转 | 调数值：时长、音量、人数 |
| 摇一摇 | 应用自定（聚会玩：掷骰子） |
| 扣下（屏幕朝下放） | 安静：停下声音、熄屏。练习类（呼吸、口语）直接结束；计时类（作业专注）继续计时、只熄屏，时间到照样提醒（声音减半），拿起亮屏 |
| 拿起 | 唤醒 |

- **侧键是下载引脚**：开机和插线时别按，引导页写一次。
- **说话的最短按住时间**：0.3 秒，短于这个当短按处理，录音丢掉、不扣点。
- **最长说话时间**：按应用（服务清单里定，`/me` 下发）。最后 5 秒边缘环变 coral 提示；最长不超过 15 秒的应用（作业伙伴问字 10 秒）只在最后 3 秒提示，免得一开口就变色。

## 7. Yay 在应用里

用 `yaykit/firmware/assets/yay` 的姿势和 `packages/yay-art` 的矢量五官（公共计划 P11 的 Yay 组件）。

| 规则 | 说明 |
|---|---|
| 一直活着 | 待机时眨眼（4–6 秒一次）、偶尔小动作；不做持续的大动画 |
| 看向说话的人 | 平放多人时眼睛看向正在说或该轮到的人 |
| 对结果有反应 | 说对了、赢了、完成了：done 或 greet；出错：help；不用哭和生气 |
| 嘴跟着声音 | 念字幕时按音量开合（闭、微张、张开三档） |
| 不抢主角 | 主角是光球或骰子时，Yay 缩到边上或只在开头结尾出现 |
| 二维码页不出现 | 首次添加、设置 › Wi-Fi、换个网络这些页只放二维码（第 1 节第 9 条） |
| 尺寸 | 主角 264；陪伴 176；角落 132 |

## 8. 进出应用

- **打开**（现在的做法）：Yay 说「好，打开呼吸之间」，同时 3 秒倒计时（短按侧键取消）；然后黑底两行「正在打开」（16 号）和应用名（24 号），等它真画到屏上再重启进应用（约 2.5 秒）。应用起来时屏幕先黑着，画好第一帧再按共享亮度亮起（`board_display_start_opts` 的 `start_dark`）。从应用环点已装的应用也是这块黑底，只是没有倒计时。见 `docs/design/device-controls.md` §11.1 第 4 条。
- **铺满帧**（设计，还没接进固件）：每个应用在界面文档里写清自己的「铺满帧」（图标放大到整屏时的那一帧，例如呼吸之间 = r 120 的奶油色光球 + r 214 的鼠尾草外圈）。Yay 画面上应用图标从 Yay 手里放大铺满，Yay 放大的最后一帧和应用的第一帧完全一样，应用再从它变成自己的主页，看起来是一个连续的动作。组件已有（`yaykit_ui` 的 `yk_transition.h`：`yk_splash_for`、`yk_ui_enter`、`yk_ui_leave`），现在只有测试固件 shared-test 在用。
- **带着参数打开**：Yay 打开时带上用户的意图（"睡前呼吸 5 分钟""鹰怎么写"），应用直接进到那一步，不再让用户选一遍。
- **回来**：双击侧键打开应用环，点中间的 Yay：黑底「正在回到 Yay」，重启回 Yay。应用留下一句结果（"呼吸了 5 分钟"），Yay 接一句话，并在自己的屏幕上画环形小结（P3）。
- **第一次进入**：最多一页引导，以动画演示为主，一句话说明手势；之后不再出现。

## 9. 统一的提示和异常

页面不换，只换 Yay 的表情和一句提示。不弹窗。

| 情况 | Yay | 提示（中 / 英） | 下一步 |
|---|---|---|---|
| 正在连网 | 待命，边缘 ink3 慢转 | 不显示文字 | 连上自动继续；按住说话照样录 |
| 一直连不上（约 45 秒） | 待命，看向用户 | 回 Yay 设置网络 / Set up Wi-Fi in Yay | 双击开应用环，点中间回 Yay |
| 设备没添加到账号 | 待命 | 先在 Yay 里添加 / Add me in Yay first | 双击开应用环，点中间回 Yay |
| 点数用完 | 待命，头顶小点 | 今天的点数用完了 / Out of points today | 离线功能照常 |
| 没听清 | help | 再说一次？ / Say it again? | 直接再按住 |
| 云端忙、出错 | help | 等一下再试 / Try again soon | 自动重试一次 |
| 内容被拦 | help | 换个话题吧 / Let's try something else | — |
| 电量低（15%、10% 各一次） | 待命 | 边缘 amber 一闪，不打断；带一行小字「电量 15%，记得充电 / Battery 15%: time to charge」（2026-10-21 起，主固件 P25；以前不带字） | 每次放电各一次；充电时不提示，拔掉后重新算 |

离线功能（计时、游戏、呼吸）在没网时完全照常，不显示任何网络提示。

**文案可以按用的人改写，意思不变**：作业伙伴对孩子不说「点数」，说「今天问够啦 / 明天再来问」，Yay 挥手；面对面翻译没有「话题」，内容被拦时说「这句翻不了」。给家长看的地方（下滑状态）仍用上表的说法。

## 10. 声音

- **音量和亮度全设备共用**：在 Yay 里调，各应用读同一个值；应用里临时调了也写回去。
- **每个应用一套音色**，统一的只有三个：确认（短、高）、拨动刻度（极短"嗒"）、出错（低两声）。
- **说话前后**：开麦前、关麦后各一个短提示音，录音里不能有它。
- **小喇叭**：中高频为主，低于 200 Hz 的声音听不到，音效要按这个设计；峰值留 3 dB，不爆音。
- **不吵**：除了语音和玩法本身，界面不叮叮响。夜间（22:00–7:00）提示音降一半。

## 11. 动效与流畅度

整屏重画很贵，所以**动的部分要小而集中，背景不动**。

| 规则 | 说明 |
|---|---|
| 小区域动 | 主角、边缘环、指针在动，背景静止；只重画变化的区域 |
| 预先画好 | 光球、骰子、Yay 的姿势都是预先画好的图，或者预先算好的颜色表，运行时只换帧、查表，不实时算渐变。呼吸之间 2026-10-09 真机测过：查颜色表约 29 帧/秒，PSRAM 里放预渲染图只有约 19 帧/秒，所以大面积的渐变优先用颜色表 |
| 粒子有上限 | 彩带、星星同时不超过 40 个 |
| 过渡要短 | 页面切换 ≤ 250 ms，缓出；字幕切换 150 ms 淡入淡出 |
| 帧率 | 目标：动的区域 30 帧以上；整屏过渡不低于 20 帧。以真机实测为准，写进各应用开发文档 |
| 音画同步 | 声音和画面的偏差不超过 50 ms（呼吸、骰子落定、转盘停下） |
| 跟手 | 拨盘、转盘跟着手指走，延迟不超过一帧 |

## 12. 屏幕与省电

- **息屏时间全设备共用**：`board_pref_screen_off_s()`（共享设置 `yk_pref`），默认 30 秒；Yay 设置页「息屏」一行可选 15 秒、30 秒、1 分钟、不息屏（P22，#245）。电量到过 15% 又没插电时，Yay 在主页 15 秒就息屏。正在说话、播放、计时、练习时不熄屏（计时可以降亮度）。
- **Yay（主固件）**：主页单击、或在主页没人动到了时间就息屏，240 ms 渐暗；息屏时面板关显示、触摸不再读（`board_display_sleep()`，#290），**触摸不亮屏**，只有侧键能亮（单击亮屏；按住亮屏并直接说话；双击亮屏并打开应用环）。服务端主动起的一轮、语音打开或安装应用、插上电也会亮屏。见 `docs/design/device-controls.md` §3。
- **扩展应用**：现在各自处理，还没改用 `board_display_sleep()`。例：聚会玩 60 秒变暗、到共享的息屏时间（不早于 63 秒）熄屏，一局进行中不变暗不熄屏；聚会玩和呼吸之间熄屏时第一下触摸只亮屏，不触发动作。
- 夜间（22:00–7:00）亮度上限 40%，呼吸之间的睡前模式按它自己的规则更暗。7 点前做唤醒练习时从 40% 起、最多亮到 60%。

## 13. 文案

- 跟账号语言。目标是四种：zh-Hans、en、ja、es-419（`docs/design/i18n.md`）。现在固件里的界面文字只有中英两套（`T(zh, en)`），日文、西语要等字符串表接进固件（`packages/strings` 的 `yaykit.*`，生成的 C 表现在是空的）；字体包已有简中和日文，拉丁字形含西语字母；字幕排版已认 `ja`、`es`。面对面翻译的开场白用对方的语言。
- 短句，口语，不用"请"开头，不用感叹号堆叠。
- 称呼：作业伙伴用"谁在用"里设的称呼；其他应用不叫名字。
- 不出现技术词（令牌、会话、服务器、错误码）。

## 14. 评审和验收

- 每个应用一份可交互原型（466 × 466 1:1，带声音），评审交互、画面和声音方向；原型画面不能当固件截图或商店素材。
- 真机用 `snap` 抓屏检查：文字不超出安全圆，画面里没有蓝色，提示不超过 8 个字。
- 流畅度用真机测：帧时间、卡顿次数、音画偏差，数字写进各应用的开发文档。
- 触摸手感、玻璃上的观感写进各应用的真机验收清单。
